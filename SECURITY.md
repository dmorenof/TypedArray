# Security policy

## Supported versions

Security fixes are intended for the latest maintained stable release of TypedArray. Until a new stable release is published, the current stable version is 1.0.2. PHP runtime versions follow the compatibility policy documented in `composer.json`.

## Reporting a vulnerability

Please **do not** disclose a vulnerability in a public GitHub issue before coordinating a fix.

If private vulnerability reporting is available for this repository, use the GitHub Security tab. Otherwise, contact the maintainer using the address published in `composer.json`; include a minimal reproducer, affected PHP and library versions, and impact.

Do not share real credentials, customer data, or other secrets in reports.

## Disclosure

The maintainer will investigate, confirm affected versions and publish a fix and advisory when appropriate. No specific response-time guarantee is currently offered.
